# Day 0 回访表（followup-day0）

换新聊天或新任务时填一次，三栏，不按天填。

基线（今天，Day 0）：这篇稿改了三处，其中两处由小满提出、我采纳。

## 三栏

```
1. 哪天 + 任务一句话：  比如 10-18，改一篇小红书稿的开头
2. 有没有再讲偏好：     没讲（原话也记下来）/ 讲了：……
3. 改了几处：           数字；没数就写"没数"，空着也等于没数，有稿了再回来补；补时捎一句：是任务简单还是它记住了，想不清就写想不清
```

## 用法

- 第 2 栏只对比"我有没有少重复解释"，第 3 栏只对比"我有没有少改一轮"，两栏都对着今天（3 处）比。
- 第 3 栏默认"没数"：边聊天边数不现实，先记数字或写"没数"，等真出了稿再回头补；空着不算漏填。
- 没换任务的那次，第 2、3 栏写"未发生"，不填推测。
