在 DeepSeekBot 中，无论是 Bot 的记忆文件（Memory）、已授权的工作区目录（Workspace），还是聊天消息中收发的附件，你都可以直接调用电脑（Host）上的本地软件打开、在文件管理器中定位，或者下载到当前设备。

## 用本地软件打开文件与文件夹

在记忆文件阅读器、聊天中的文件卡片，以及「记忆仓库（Memory Repository）」和已授权工作区文件夹所在行，都会提供一个 **打开** 分体按钮：

- **直接打开**：点击主按钮，会使用 Host 电脑上的默认应用打开该文件或文件夹。
- **使用指定应用打开**：点击右侧下拉箭头，会列出系统检测到的其他可用软件（如 VS Code、Cursor、Sublime Text、Finder / 资源管理器等）。从中选择某个应用只会用它打开这一次，不会改变默认设置。
- **设置默认打开方式**：在下拉菜单中选择 **设置…的默认应用**，可以为该文件类型（例如 `.md`）或文件夹记住你偏好的打开软件；选择 **恢复系统默认** 即可清除该偏好。

> **关于默认应用的说明**：
> - 这里的默认应用设置仅保存在当前浏览器与当前 DSH 环境中，不会修改你操作系统的全局文件关联。
> - 文件夹在首次点击「打开」时会请你选择一个偏好的软件（如文件管理器或代码编辑器）。
> - 如果之前记住的默认软件在电脑上已被卸载或不可用，按钮会明确提示并请你重新选择，不会静默替换成其他软件。

### 在「记忆演化」中打开文件

在右侧栏的 **记忆演化** 中，查看历史提交差异（Commit Diff）或未提交更改时，每个文件行都带有 **打开当前文件** 按钮：

- 它打开的是该路径在磁盘上**当前最新**的文件，而不是历史某次提交中的旧快照。
- 如果文件经过重命名，差异列表中会分别显示旧路径（已删除）和新路径（新增），请在**新路径**那一行点击打开。
- 如果该文件在当前已被删除，按钮会明确提示文件已不存在，不会从历史记录中自动重建文件。

### 更多文件操作菜单

在记忆文件列表行或聊天消息的附件卡片上（点击文件卡片、右键点击文件/图片，或点击 `···` 更多按钮），你还可以使用以下操作：

- **在文件管理器中显示**：在 macOS Finder 或 Windows 资源管理器中定位并高亮该文件。
- **在编辑器中打开**：用你选择的外部编辑器直接打开。
- **复制 Host 路径**：复制该文件在运行 DSH 的电脑上的完整本地路径。
- **下载到当前设备**：将文件直接通过浏览器下载到你当前使用的设备上。点击聊天中的图片仍会直接打开大图预览。

> **远程访问提示（如使用 Tailscale 或 Cloudflare Tunnel）**：
> 菜单中标有 Host 电脑的操作（如打开编辑器或文件管理器）会在**运行 DSH 服务的电脑**上弹出窗口；而 **下载** 则会把文件传输到你**当前打开浏览器的设备**上。如果你下载了文件并在本地修改，修改不会自动同步回 Host 电脑。

## 直接编辑聊天附件

当你在本地聊天中发送文件时，DeepSeekBot 会将该附件保存在当前环境的受管附件目录中：

- **原位编辑与即时保存**：当你通过文件卡片的菜单在 Host 的外部软件中打开该附件并保存修改后，修改会直接作用于这封消息所关联的附件文件。保存后刷新频道，再次预览、读取或下载该附件时，看到的就是修改后的最新内容与文件大小。
- **与本地原文件互不影响**：上传附件相当于将文件放入了 DeepSeekBot 的受管空间。你在外部修改聊天附件不会改动你上传前的原始本地文件；两次独立上传哪怕内容相同也是各自独立的文件，互不干扰。

## 外部渠道（如飞书 / Lark）文件卡片

对于从飞书 / Lark 等外部 IM 渠道收到的文件消息，文件卡片采用**按需获取**机制：

- 浏览聊天或收件箱卡片时，只展示文件名等基本信息，不会自动在后台下载远端大文件。
- 点击文件名即可将文件下载到当前设备；下载过程中会显示加载状态，若网络异常可随时点击重试。
- 当 Host 支持本地打开文件时，外部文件卡片同样提供应用菜单入口；不过在本地软件中编辑已下载的外部附件副本，不会反向修改飞书等外部平台上的原始文件。

## 让 PersonaBot 处理或修改文件

除了你自己打开文件外，你也可以让 Bot 帮你处理收到的附件（例如解压处理包含 CSV 的 ZIP 压缩包并生成新报告），或者直接修改原附件。

### 方式一：处理文件并生成新附件回复

1. **开启工作区写入权限**：在 Bot 私聊的右侧栏展开 **工作区授权（Workspace Grants）**，添加一个用于处理文件的工作文件夹，展开该行并开启 **允许 Bot 写入此文件夹**（默认关闭，仅为你希望 Bot 生成和保存文件的目录开启即可）。
2. **发送文件并提出要求**：在本地私聊（或在已授权的飞书群/话题中上传文件并 `@Bot`）发送任意格式的附件，告诉 Bot 你的处理要求。
3. **自动处理与回传**：Bot 会将附件另存为工作区内的独立副本（不会覆盖同名已有文件），调用文件工具或经你批准的终端命令完成处理，然后将生成的新文件作为可下载的附件回复给你（在飞书中会直接以文件形式回复在原话题下）。

### 方式二：让 Bot 直接查看或修改原附件

- **查看附件**：直接在聊天中让 Bot 读取你指定的消息附件即可。
- **修改原附件**：如果你希望 Bot 直接修改某条消息里的附件本身（而不是另存新文件），可以在消息中明确告诉它“修改这个原件”（例如：“把这个原件 `status.txt` 中的 `status=pending` 改成 `status=approved`”）。
- Bot 请求修改原附件时，会触发工具审批提示。你确认批准后，Bot 会直接更新该附件，刷新频道后从原消息下载或打开即可看到最新内容。
