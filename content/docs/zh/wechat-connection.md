通过个人微信接入，你可以直接在手机微信中与你的 PersonaBot 一对一对话。无需搭建服务器或配置公网回调，只需在本地使用微信扫码绑定，即可在微信里发文字、传文件、发图片、发语音，并收到 Bot 的智能回复。

## 适用范围与特性

- **一对一私聊专属**：仅支持你本人（扫码账号）与该微信 Bot 之间的一对一私聊；不支持微信群聊、其他联系人消息转发或企业微信。
- **全多媒体支持**：支持文字交流、文件收发（小于 25 MiB）、图片理解与回传、微信语音转写及原始音频工具处理。
- **快捷指令控制**：在微信私聊中支持直接使用 `/status`、`/model`、`/effort`、`/new` 等斜杠指令管理 Bot 状态。
- **本地凭证安全**：扫码凭据与聊天记录保存在你本机，不通过任何第三方云端中转。

## 1. 扫码连接微信 Bot

1. 打开 DSH 界面左下角 **设置 → IM 机器人 → 微信**。
2. 点击 **扫码绑定**，界面会生成一个专用的连接二维码。
3. 打开手机微信扫描该二维码并在手机上确认登录。
4. 稍等片刻，本地界面会显示微信账号已成功连接。手机微信的聊天列表中会出现该 Bot 的私聊会话。

> 提示：二维码为临时登录凭据，切勿截屏分享给他人。连接断开或重启 DSH 后，本地已保存的 Profile 会自动尝试恢复连接。

## 2. 将微信账号绑定到 PersonaBot

1. 在 **Bot 模式** 中打开你想要绑定的 Bot 私聊界面。
2. 展开右侧栏的 **外部身份（External identities）**，点击 **+ 绑定应用**。
3. 在应用下拉列表中选择刚刚连接的微信账号并确认。
4. 绑定成功后，状态会显示为 **已就绪**。现在，你在微信中给该 Bot 发送的任何消息都会直接进入它的收件箱。

## 3. 测试与验证回复

1. 在手机微信中打开与该 Bot 的私聊窗口，发送一条测试文字（例如：“你好，请回复 WECHAT-OK”）。
2. 在 DSH 中打开该 Bot 私聊的右侧栏，展开 **Bot 收件箱**，可以看到接收到的微信消息记录。
3. 稍等数秒，手机微信中就会收到 Bot 调用大模型生成的正式回复。

## 4. 多媒体消息处理

除了纯文本外，你可以在微信私聊中发送更多类型的消息：

### 接收与处理文件

- 在微信中直接给 Bot 发送文件（单个文件小于 25 MiB，如文档、表格、代码压缩包）。
- Bot 收到文件后，会自动将其保存在授权的工作区中，并调用工具进行解析、分析或修改。
- 当任务完成需要回传产物时，Bot 会直接将生成的结果文件以微信文件的形式发回你的微信私聊中。

### 发送与回传图片

- 在微信中给 Bot 发送照片或截图，可附带文字说明。
- Bot（需配置支持多模态视觉的模型，如 DeepSeek Flash 或类似模型）会读取图片细节并回答你的问题。
- 若执行的任务涉及生成图表或处理图片，Bot 也可以将生成的图片直接发送回微信。

### 语音消息与转写

- 在微信中直接按住说话发送语音消息。
- 微信官方转写文字会自动送入 Bot 收件箱进行回复。
- 在本地 Bot 收件箱的详情页中，你还可以查看语音时长，或者点击“准备播放”收听转换后的音频。

## 5. 在微信中使用快捷斜杠指令

你可以在微信私聊中单独发送以下指令（独占一行），直接查看或控制 Bot 状态，无需消耗模型 Token：

| 快捷指令 | 功能说明 |
| --- | --- |
| `/status` 或 `/状态` | 查看 Bot 当前的主对话模型、任务模型及工作状态 |
| `/model` 或 `/模型` | 列出可切换的模型列表 |
| `/model <名称或序号>` | 将当前 Bot 的主对话模型切换为指定模型 |
| `/effort <low\|medium\|high>` | 调整模型的思考与推理强度 |
| `/new` 或 `/新建` | 归档并重置当前对话，开启新的一轮对话（保留 Bot 长期记忆） |
| `/compact` 或 `/压缩` | 压缩当前会话的上下文历史，释放上下文窗口 |
| `/stop` 或 `/停止` | 紧急中断 Bot 正在执行的后台推理或任务 |

## 常见问题排查

| 现象 | 排查方向 |
| --- | --- |
| 二维码扫码后提示过期 | 刷新二维码并尽快在手机微信上确认授权。 |
| 发送消息后 Bot 没有回复 | 确认本地私聊中该 Bot 能正常调用模型、外部身份中微信账号状态为“已就绪”，且没有将该会话设置为“静音”或“屏蔽”。 |
| 文件发送后提示过大 | 微信单文件传输上限为 25 MiB，请将大文件分卷压缩或精简后再发送。 |
| 发送图片后 Bot 无法识别 | 检查当前 Bot 配置的主模型是否支持视觉输入；若模型仅支持纯文本，需更换为多模态模型。 |
| 重新登录微信后状态失效 | 重新扫码登录会生成新的会话凭证，只需在外部身份中重新确认绑定即可。 |
