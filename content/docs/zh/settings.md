本页汇总了 **DeepSeekBot** 的各项非 IM 设置：从哪里打开、每个参数的作用，以及修改后的生效范围。阅读本页前，建议先完成 [安装](/zh/docs/installation) 和 [API 与 Bot 模型配置](/zh/docs/model-setup)。飞书 / Lark、Slack 等外部渠道的连接参数请参考对应的连接教程。

## 设置入口速查

| 要设置什么 | 打开位置 |
| --- | --- |
| DSH 外观、语言、默认权限、输入行为 | 左下角「设置 → 通用设置」。 |
| API 提供商和模型目录 | 「设置 → 模型」；详见 [API 与 Bot 模型](/zh/docs/model-setup)。 |
| 原生 Agent 的工具和工作方式 | 「设置 → Agent 预设」。 |
| Bot 图标、动效、排序、并发、你的默认称呼 | 左侧 Bot 模式旁的「Bot 设置」，或「设置 → Bot 设置」。 |
| 单个 Bot 的名称与头像 | Bot 私聊顶部的名称 / 头像 →「查看详细」。 |
| 单个 Bot 的模型与唤醒策略 | Bot 私聊频道设置（顶部 `···` 菜单）中的「模型」和「唤醒策略」。 |
| 右侧栏的顺序、显示、会话视图 | 右侧 Channel sidebar 顶部的齿轮按钮。 |
| 单个 Bot 的工作目录与任务权限 | Bot 私聊频道设置中的「工作区授权」。 |
| 当前 DSH Session 的模型和权限 | 从右侧「会话」打开目标 Session，在该会话的原生控件中查看。 |

## 完整环境备份与恢复

如果你想将整个 DeepSeekBot 环境迁移到新电脑，或者为当前环境做一份完整快照，可以使用完整环境备份功能。

进入 **Bot 设置 → 完整环境备份与恢复 → 管理备份**：

1. **预览导出**：查看当前环境包含的历史 Bot 身份总数、受管文件数、估算体积，以及不会包含在备份中的底层原生 Session 数量。
2. **下载已验证备份**：生成一个 `.botharness-backup` 备份包，完成后会显示实际压缩大小。

### 备份包含与不包含的内容

- **包含内容**：完整的 BotHarness 数据库、所有 Bot 的记忆仓库（包含自定义路径及已删除身份保留的记忆库）、聊天附件与身份绑定、模型预设与各 Bot 的模型配置、运行依赖以及数据完整性校验信息。
- **不包含内容**：API 密钥与账号凭据、可执行插件代码、工作区（Workspace）普通项目文件，以及底层 DSH Session 的对话正文。源机器的本地 Git 配置会被替换为安全默认值，Git hooks 会在恢复时隔离。

> **隐私提示**：备份文件中包含完整的聊天记录、记忆内容、账号信息、授权设置与操作历史，请妥善私密保存。此外，这是整个环境的备份，与单个 Bot 的「导出 `.bot.zip` / Git 分享」（用于克隆出新身份）不同。

### 恢复环境到新目录

你可以在备份管理页面选择一个 `.botharness-backup` 文件，检查其清单、数据库完整性、文件数量、体积和 SHA-256 校验值。确认无误后，在终端中使用本地命令将备份恢复到一个**尚未存在的新目录**：

```text
botharness-profile restore --file "environment.botharness-backup" --new-home "new-environment"
```

如果你使用的是源码仓库，可以运行 `node scripts/profile-restore.mjs` 并传入相同参数。恢复过程不会直接覆盖正在运行的环境，目标目录如果已存在会被拒绝，从而保护现有数据安全。

### 恢复后的安全激活流程

恢复完成后，使用你的 DSH 客户端指向该新目录启动环境（开发环境可运行 `node scripts/dev-instance.mjs --home <新目录> --port <端口>`）。

为了防止新旧设备同时运行同一个 Bot 导致消息冲突或重复触发，恢复后的环境默认处于**安全暂停（灾难恢复）状态**：

- 所有 Bot 默认暂停；外部账号绑定、触发器、已保存的工具授权和定时任务均处于挂起状态。
- 工作区目录需要重新映射，浏览器与电脑操作权限默认关闭，历史收发队列不会自动重放。
- 你可以直接浏览历史聊天记录和记忆文件。

**重新激活 Bot 的步骤：**

1. 前往 **设置 → 模型** 配置当前设备上的 API 密钥，并在 Bot 资料中确认模型设置。
2. 回到 **管理备份** 页面刷新准备状态，点击 **授权此目标模型**。
3. 确认旧设备上的相同 Bot 已停用（避免双活冲突），点击 **激活此 Bot**。
4. 发送一条新私聊即可开始对话（会保留原有身份并开启新的主会话）。如果需要恢复外部 IM 账号连接，请按各渠道教程重新授权连接。

## DSH 通用设置

这些是 DSH 的原生全局设置。下拉选择器和开关会立即保存，带「保存」按钮的输入框需点击保存后生效。

![DSH 通用设置中的全部主要参数](/guides/settings/settings-general-zh.webp)

| 参数 | 选项 / 默认值 | 用途与作用范围 |
| --- | --- | --- |
| 权限 | 仅可查看 / 工作区内修改 / 完全权限（默认：工作区内修改） | 新建原生会话的默认权限。Bot 的后台任务权限在「工作区授权」中单独设置。 |
| 语言 | 中文 / 英文 | 切换界面显示语言。 |
| 外观 | 浅色 / 深色 / 跟随系统（默认：跟随系统） | 切换 DSH 界面主题。 |
| 字号大小 | 默认 14 px，可用增大 / 减小按钮调整 | 调整会话正文区域的字体大小。 |
| 工作步骤展示 | 简洁 / 标准 / 详细 / 完全展开（默认：详细） | 控制工具调用细节的展示程度，不影响工具的实际权限。 |
| 性能与用量 | 简洁 / 详细（默认：详细） | 控制性能指标与 Token 信息的展示程度。 |
| 代码工作工具 | 开 / 关（默认：开） | 显示执行轨迹、本轮代码差异，以及新对话中的 Agent 预设切换入口。 |
| 快捷键 | 点击「编辑快捷键」 | 查看并自定义操作快捷键，支持冲突提示与恢复默认。 |
| 繁忙时的发送行为 | 默认「排队发送」，可选「插话发送」 | 控制 Agent 运行时按 Enter / 发送按钮的提交方式（`Cmd/Ctrl + Enter` 会执行另一种方式）。与 Bot 的唤醒策略相互独立。 |
| 在使用官方模型 API 时上传 Session Log | 开 / 关 | 决定是否通过官方模型 API 上传会话日志以帮助改进模型与产品，可按你的偏好自由开关。 |
| 打开配置文件 | 按钮 | 打开当前 Profile 的原生配置文件；日常修改建议优先使用界面表单。 |

## Agent 预设与内置插件

**Agent 预设** 决定原生 Agent 的工具集和工作模式。点击某个预设的「设为新任务默认」后，会对之后新建的原生任务生效。它与 [Bot 模型预设](/zh/docs/model-setup) 是两项独立的设置。

![DSH 的 Agent 预设：选择工具和工作方式](/guides/settings/settings-agent-presets-zh.webp)

| 预设 | 适用场景 |
| --- | --- |
| 标准模式（默认） | 绝大多数代码、文件和资料处理任务。 |
| PTC 模式 | 需要批量调用工具，并对结果进行筛选、去重、统计和汇总的任务。 |
| 极简模式 | 仅使用终端工具完成任务，适合基础表现测试和对比。 |
| 创造模式 | 编写 DSH 插件，组合工具和提示词来扩展 DSH。 |
| 自定义 | 点击「让 Agent 帮我创建预设模式」，按需定制专属预设。 |

在 **内置插件** 页面中，你可以搜索插件、按「会话插件」与「全局插件」筛选，并查看各插件在不同 Agent 预设下的启用状态与参数详情。插件包的安装与启用方法请参考 [安装教程](/zh/docs/installation)。

## 外观与壁纸

打开 **Bot 设置 → 界面设置**（在 Bot 模式下，macOS 按 `⌘,`、Windows/Linux 按 `Ctrl+,` 可直接打开 Bot 设置）。本页设置仅保存在当前设备的客户端（网页端和桌面端各自独立保存），不会改变 DSH 原生主题。

| 设置项 | 选项 | 作用 |
| --- | --- | --- |
| 主题 | 浅色、深色或跟随系统 | 设置 Bot 模式自身的明暗主题。 |
| 配色与主色 | 经典蓝、雾紫、森林绿、暖琥珀，或自定义主色 | 浅色和深色模式可分别设置各自的配色。 |
| 面板标题栏 / 内容底色 | 底色、不透明度、背景模糊 | 作用于当前模式下的所有面板；文字和消息气泡保持各自原本的颜色以确保可读性。 |
| 壁纸库 | 最多 24 张；图片最大 20 MB，静音视频最大 100 MB | 点击「添加壁纸」或直接拖入多个文件，选中一张或选「无」；点击「调整取景」可设置位置和缩放。首次设置壁纸时，未单独调整过的面板会自动变为半透明。 |
| 自动切换 | 关闭、每 1 / 5 / 15 / 30 分钟、每小时；支持「随机顺序」 | 在壁纸库中自动轮换。视频壁纸会静音循环播放，切到后台时自动暂停。 |
| 恢复外观 | 「清除面板单独设置」「恢复默认外观…」 | 前者清除当前模式下各面板的单独样式；后者在确认后恢复浅色/深色模式的默认外观并清空壁纸库（不影响 Bot 数据和布局）。 |

如果你想单独调整某一个面板的透明度或底色，可以点击该面板标题栏右上角的菜单 → **外观设置**。每一项都可以选择跟随全局或单独设置，点击「恢复此面板」即可清除单独设置。你也可以通过 CLI 命令调整外观与壁纸，详见 [CLI 指南](https://github.com/BotHarness/BotHarness/blob/main/docs/bot-cli.zh.md#设备本地-deepseekbot-外观)。

## 上下文压缩

Bot 的主会话（Orchestrator Session）会随着每轮对话不断增长。上下文压缩会用精炼摘要替换冗长的历史记录，让后续消息响应更快、消耗更少 Token。

- **立即压缩**：在 Bot 私聊输入框输入 `/compact`，在外部 IM 私聊发送 `/compact`（或 `/压缩`），或运行命令 `deepseekbot bot-compact <bot-id>`。压缩完成后会显示压缩前后的 Token 数量。如果 Bot 正在回复中，请先等待其完成或停止当前回合。
- **空闲时提前压缩上下文**：位于 **Bot 设置 → 模型与运行**，默认开启。当 Bot 处于安静空闲状态达到模型提示缓存（Prompt Cache）寿命的一半时（最少 15 分钟），系统会趁缓存尚未失效自动压缩会话，比等缓存过期后再压缩更加节省成本。自动压缩不会打扰聊天界面，每次执行都会记录在 Bot 的活动概览中。更多细节请参考 [CLI 指南](https://github.com/BotHarness/BotHarness/blob/main/docs/bot-cli.zh.md#空闲压缩idle-compaction)。

如果某一轮对话因为单次请求内容过大导致上下文溢出，界面会直接提示错误，请精简当次发送的内容后重试。

## 快速搜索与快捷键

在 Bot 模式下按 **Alt+K**（macOS 为 `Option+K`，部分浏览器中也支持 `Ctrl+K` 或 `⌘K`），即可快速搜索 Bot、群聊、频道以及 Bot 设置里的具体配置项。中文名称支持全拼或拼音首字母搜索。选中设置项后会直接打开对应页面并高亮该行。

按 `?` 或 `Ctrl/⌘ + /` 可随时查看全部快捷键列表，也可以在 **Bot 设置 → 键盘快捷键** 中自定义按键。

## 创建 Bot 与编辑资料

在 Bot 模式中点击「创建第一个 PersonaBot」或列表顶部的「新建」即可创建 Bot。

| 参数 | 配置说明 |
| --- | --- |
| 来源 | 「空白」会创建全新的记忆仓库；「从 Git 导入」可填写可访问的 Git 仓库地址，直接使用该仓库中的记忆与设定。 |
| 名称 | 必填显示名称；创建后可在 Bot 资料页点击名称旁的编辑按钮随时改名。 |
| 岗位 | 可选展示标签；输入后按 Enter 或逗号确认，点击标签上的关闭按钮即可移除。 |
| 简介 | 可选简短介绍，展示在 Bot 资料卡片中。 |
| 人格模板 | 提供空白、同事、角色扮演等预设模板，作为创建时的人格文本起点。 |
| 人格 | 创建时可编辑的核心设定文本，决定 Bot 的身份认知和交流方式。 |

![创建 Bot 的来源、名称、岗位、简介与人格选项](/guides/install/06-create-bot-zh.webp)

创建完成后，点击聊天顶部的 Bot 名称或头像 → **查看详细**，可以管理以下内容：

- **更换头像**：上传 PNG、JPEG 或 WebP 图片，裁剪调整后保存；已上传的头像可随时移除。
- **设计头像**：自由搭配插画或线条风格、预设、五官部件、形状滑块和配色。点击保存后生效；如果同时上传了自定义图片，界面会优先展示上传的图片。
- **活动概览**：可通过图钉按钮选择将哪些统计卡片固定在资料悬浮窗中。Token 用量支持在 **每日总量** 和 **按模型** 之间切换，支持 7 / 30 / 90 天、全部时间或通过 `⋯` 菜单自定义日期范围；将鼠标悬停在柱状图上可查看缓存输入、非缓存输入与输出 Token 的详细拆分。
- **人格与记忆文件**：在聊天右侧栏的「记忆文件」中直接查看、预览和编辑 `SOUL.md`、`MEMORY.md` 等文件。
- **常驻记忆上限**：位于 **Bot 私聊 → 记忆文件 → 常驻记忆上限**，用于调整 `SOUL.md` 与 `MEMORY.md` 的字符上限，从下一个会话或当前会话下次压缩时生效；详见 [Bot 灵魂与核心记忆](/zh/docs/soul-and-core-memory)。
- **外部身份与外部连接器**：同样位于 Bot 私聊右侧的 Channel sidebar，详见 [外部身份](/zh/docs/channel-sidebar/external-identities) 与 [外部连接器](/zh/docs/channel-sidebar/external-connectors)。

## Bot 唤醒策略与本地群聊

Bot 的 **唤醒策略** 位于私聊右侧的 Channel sidebar。打开 **Bot 私聊 → Channel sidebar → 唤醒策略**，点击对应来源行即可修改触发规则并保存，点击「恢复默认」可撤销自定义修改。各来源的详细规则说明请参考 [唤醒策略](/zh/docs/channel-sidebar/wake-policy)。

在本地群聊中，你可以点击顶部 **群名 / 头像 → 查看详细**，为群内的每个成员 Bot 单独设置普通消息提醒规则（可选择继承该 Bot 的默认规则，或仅在该群内覆盖），也可以在群管理中邀请成员、处理入群申请。

## Channel sidebar 显示设置

关于右侧栏的完整功能介绍，请参阅 [Channel sidebar 章节](/zh/docs/channel-sidebar)；标签页增删、排序与隐藏的详细操作请参考 [显示与布局](/zh/docs/channel-sidebar/display)。

点击聊天顶部的 **··· → 频道设置…** 可直接打开当前聊天的模型、工作区授权、唤醒策略、外部身份、外部连接器或群管理。侧栏各分区标题右侧的齿轮按钮用于调整当前浏览器的显示偏好，不会影响 Bot 的记忆数据或任务权限。

![右侧栏齿轮的顺序、记忆术语和会话显示菜单](/guides/settings/settings-sidebar-zh.webp)

| 参数 | 默认值与作用 |
| --- | --- |
| `+ 视图`（标签页旁） | 勾选要显示的标签页并拖动排序，立即生效；Bot 私聊和群聊可以保存不同的布局。 |
| 编辑侧边栏（窄窗口模式） | 拖动调整顺序、勾选要显示的入口，完成后点击确认。 |
| 记忆演化 → 显示术语 | 默认使用直观的「记忆术语」，可切换为「Git 术语」（展示同一份提交记录的不同称呼）。 |
| Bot 收件箱 → 呈现方式 | 默认按时间排列，可切换为按来源分组。 |
| 会话 → 会话范围 | 默认显示「当前」相关会话，可切换为「全部」。 |
| 会话 → 排列方式 | 默认按状态（进行中 / 空闲）分组，可切换为按工作区分组。 |
| 侧栏宽度 | 默认 320 px，可拖动分隔条在 260–560 px 之间自由调整，刷新后会自动记住宽度和展开状态。 |

## 工作区授权与任务权限

在目标 Bot 私聊的 **频道设置**（顶部 **··· → 频道设置…**）中打开 **工作区授权**。Memory Repository 是该 Bot 默认的专属记忆目录；如果你希望 Bot 读写电脑上的代码库或文档文件夹，可以点击「添加文件夹」在目录浏览器中选择。

![没有额外授权目录时的工作区授权面板](/guides/settings/settings-workspace-grants-zh.webp)

| 参数 / 操作 | 作用与生效范围 |
| --- | --- |
| 添加文件夹 | 选择允许当前 Bot 访问的本地文件夹，确认后即完成工作区授权（每个 Bot 独立管理）。 |
| 目录撤销 / 移除 | 撤销对该文件夹的授权，后续任务将无法继续访问该目录（不会删除你电脑上的实际文件）。 |
| 新事项允许所有文件访问 | 默认关闭：新建后台任务（Assignment）仅限在已授权工作区内写入，遇到敏感操作会逐次询问。开启后新建任务将拥有完整文件访问权限（不影响已创建任务的权限）。 |
| 工具批准规则 | 当 Bot 请求执行工具时，你可以选择仅允许一次、记住具体操作或设置更宽泛的规则；已保存的规则可在此处查看详情或随时撤销。 |
| 开发者模式中的历史 / 高级选项 | 开启开发者模式后，可在此查看已撤销的授权历史记录。 |

初次使用时，建议先为 Bot 添加一个明确的项目文件夹，并保持默认的任务权限。

## 匿名使用统计

DeepSeekBot 默认会由本地服务发送精简的匿名使用统计，首次进入 Bot 模式时会弹窗说明。所有统计事件仅关联一个保存在本地 `$DSH_HOME/botharness/telemetry.json` 的随机安装 ID：

- `plugin_started`：插件版本、DSH 版本、操作系统类型和硬件架构。
- `bot_created`、`bot_archived`、`bot_deleted`、`marketplace_bot_installed`、`avatar_edited`：仅记录发生了该操作本身。
- `connector_enabled`：仅记录启用的连接器类型（`feishu`、`lark`、`slack`、`discord`、`weixin` 或 `other`）。
- 首次引导与新手教程：记录引导步骤浏览、跳过/完成状态、主题类别（如切换了配色或壁纸）以及社区链接点击情况；**不包含**模型名称、壁纸文件或你输入的任何文字。
- `daily_usage`：每天最多汇总发送一次，记录当前 Bot 数量、自上次汇总以来新增的会话数和消息数，以及统计时长（整小时数）；不会按单条消息发送事件。
- `$exception`：当后台的 BotHarness 代码出现未捕获异常时，仅记录错误类型、调用栈中的函数名、行号及包内相对路径（如 `@botharness/core/dist/index.mjs`），**绝不包含**错误信息正文或你的个人文件路径。

**我们绝不会收集或发送**：你的名字、Bot 的人格或记忆内容、聊天对话、提示词、工具调用参数、Git 仓库地址、连接器账号、工作区路径、API 密钥或 IP 地址。

**如何关闭**：打开 **Bot 设置**，关掉 **匿名使用统计** 开关即可。关闭操作立即生效、无需重启，未发送的队列事件会被立即清空，且设置会持久保存在本地。部署环境也可以通过插件配置 `telemetry: false`，或在启动时设置环境变量 `DO_NOT_TRACK=1` 或 `BOTHARNESS_TELEMETRY=0` 强制关闭。详情请参阅 [隐私说明](https://deepseekbot.botharness.ai/privacy) 和 [源码实现](https://github.com/BotHarness/BotHarness/tree/main/packages/core/src/telemetry)。

## 高级参数与可选能力

公共 npm 包 **`deepseekbot`** 默认集成了核心服务（Core）、客户端界面（Client）、浏览器工具（Browser）、电脑操作工具（Computer）以及 IM 渠道支持。首次安装后，所有外部 IM 账号默认处于未连接状态，每个 Bot 的浏览器和电脑访问权限也默认关闭，均需你按需为指定 Bot 显式开启。

- **Core 配置项**：如 `enabled`、`agentPreset`、`activityDetailConsumers`、`telemetry` 等底层配置键，详见 [Core 配置参考](/zh/dev/reference/config)。
- **Browser 与 Computer 进阶配置**：详见 [Browser 配置定义](https://github.com/BotHarness/BotHarness/blob/main/packages/browser/src/index.ts) 与 [Computer 配置定义](https://github.com/BotHarness/BotHarness/blob/main/packages/computer/src/index.ts)。对应的使用教程请参考 [分享浏览器标签页](/zh/docs/daily-browser) 与 [Computer 导出与迁移](/zh/docs/computer-export)。
- 如需通过配置文件批量部署无界面表单的底层参数，可参考 [DSH 官方文档](https://deepseek-harness.github.io/deepseek-harness/develop/basic/publish) 在 Profile / Patch 层进行配置。
