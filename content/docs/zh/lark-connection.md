通过飞书 / Lark 企业自建应用，你可以把 PersonaBot 接入飞书或 Lark 的工作空间中。用户在私聊中给机器人发消息，或者在群聊中 `@` 机器人，消息都会进入 Bot 的收件箱，Bot 会直接在原会话中进行回复。

在开始前，请先按照[安装指南](/docs/installation)完成插件安装，并在本地私聊中给 Bot 发一条消息，确认模型能正常回复。

## 核心概念与分工

| 设置项 | 入口位置 | 作用说明 |
| --- | --- | --- |
| **IM 应用连接** | 设置 → IM 机器人 → 飞书 / Lark | 管理本机与飞书/Lark 应用之间的长连接凭据（App ID 与 App Secret） |
| **外部身份** | Bot 私聊 → 右侧栏 → 外部身份 | 将已连接的应用绑定到当前 Bot，并管理会话的准入、静音、规则与屏蔽 |
| **外部连接器** | Bot 私聊 → 右侧栏 → 外部连接器 | 高级设置：将飞书群聊实时同步到本地 Channel，或配置备用的主动发送目标 |

飞书（国内版）与 Lark（国际版）是两个独立的平台。创建应用时请确认你的组织属于哪个平台：使用飞书组织请访问飞书开放平台，使用国际版组织请访问 Lark 开放平台。

## 1. 在开放平台创建并配置机器人应用

1. 打开 [飞书开放平台](https://open.feishu.cn/app)（国内版）或 [Lark 开放平台](https://open.larksuite.com/app)（国际版）。
2. 点击 **创建企业自建应用**，填写应用名称与图标（例如“AI 助手”）。
3. 进入应用详情页，在 **添加应用能力** 中添加 **机器人** 功能。
4. 在 **凭证与基础信息** 页面中，找到 **App ID** 和 **App Secret**（稍后需要填入本机设置中）。
5. 打开 **权限管理**，切换到 **应用身份权限（Tenant token scopes）**，按需添加以下权限：
   - `im:message.group_at_msg:readonly`：接收群聊中 `@` 机器人的消息（基础群聊功能必需）。
   - `im:message.p2p_msg:readonly`：接收与机器人的单聊私聊消息（单聊功能必需）。
   - `im:message:send_as_bot`：以机器人身份发送与回复消息（回复消息必需）。
   - `im:message:readonly`：读取消息内容与资源，用于回复前的安全校验与上下文构建。
   - `im:message.group_msg`（可选）：获取群内全部普通消息。仅当你希望 Bot 能在不被 `@` 的情况下监听群聊或生成总结时申请。
   - `im:resource`（可选）：上传图片或文件资源。
6. 打开 **事件与回调 → 事件配置**，选择 **使用长连接（persistent connection）**，并添加事件 `im.message.receive_v1`（接收消息）。
   > 提示：如果开放平台提示需要先建立连接才能保存长连接配置，可以先在本地完成下一步的“连接应用”，再回到网页中保存事件配置。
7. 进入 **版本管理与发布**，创建新版本并提交发布。根据组织设置，可能需要组织管理员在飞书管理后台审批后才会正式生效。
8. 将已发布的机器人拉入你需要测试的飞书群聊中。

## 2. 在本地连接飞书应用

1. 打开 DSH 界面左下角 **设置 → IM 机器人 → 飞书**。
2. 选择 **手动接入**，并在应用平台中选择 **飞书** 或 **Lark（国际版）**。
3. 填入刚才获取的 **App ID** 与 **App Secret**，点击 **绑定并连接**。
4. 连接成功后，状态会显示为 **运行正常**。凭据仅保存在你本机，不会上传到云端。

## 3. 将应用绑定到 PersonaBot

1. 在 **Bot 模式** 中打开你想要绑定的 Bot 私聊界面。
2. 展开右侧栏的 **外部身份（External identities）**，点击 **+ 绑定应用**。
3. 在下拉列表中选择刚刚连接好的飞书应用并确认。绑定成功后，状态会变为 **已就绪**。
4. 设置 **新会话准入策略**：
   - **自动接收（默认）**：当有新的私聊或群聊首次给机器人发消息时，自动加入活跃会话列表并开始回复。
   - **先问我**：新会话会先进入 **等待处理** 列表，由你在界面中手动点击允许后，Bot 才会开始回复该会话。

在外部身份的会话列表中，你可以对任意一个群或私聊进行精细化控制：
- **静音**：保留该会话，但不再因此唤醒 Bot。
- **规则**：设置是否允许在没有 `@` 的情况下接收群内普通消息。
- **屏蔽**：拒收该会话的消息，直到你手动解除屏蔽。

## 4. 测试与验证回复

1. 在飞书测试群中 `@` 该机器人，或者直接给机器人发送一条私聊消息，例如：“你好，请回复 LARK-OK”。
2. 打开 Bot 私聊右侧栏的 **Bot 收件箱**，可以看到接收到的事件详情（包含来源群、发送人姓名与消息内容）。
3. 稍等片刻，在飞书群或私聊中即可看到 Bot 调用模型后返回的正式回复。

## 5. 高级功能：群聊同步与审批通知

### 将飞书群同步到本地频道

如果你希望在本地群聊中统一查看团队在飞书里的讨论，可以在会话列表中点击该飞书群右侧的 **同步**，选择一个本地频道。之后飞书群内的提及也会同步显示在本地频道中，而 Bot 的回复依然会直接发回飞书群。

### 移动端审批卡片

当你在飞书私聊中向机器人发送 `/pair` 指令时，可以在本地界面的 **IM 管理员配对** 中将你的飞书账号授权为管理员。之后，当 Bot 在执行代码或访问本地文件需要权限审批时，可以直接在飞书私聊中向你推送交互式卡片，点击卡片上的 **允许** 或 **拒绝** 即可远程完成审批。

## 常见问题排查

| 现象 | 排查方向 |
| --- | --- |
| 无法连接或提示凭据错误 | 确认平台是否选对（飞书 vs Lark 国际版）、App ID 和 App Secret 是否完整复制无空格。 |
| 绑定应用下拉列表为空 | 确认已在“设置 → IM 机器人”中成功连接，且该应用未被其他 Bot 占用（一个应用同时只能绑定一个 Bot）。 |
| 群里 `@` 机器人无响应 | 检查机器人是否已拉入群内、应用版本是否已通过管理员审批并发布、`im:message:send_as_bot` 权限是否开通，以及本地私聊模型是否工作正常。 |
| 私聊可以回复，但群聊不行 | 确认是否申请了 `im:message.group_at_msg:readonly` 群聊事件权限，并检查该群是否处于“等待处理”或“静音”状态。 |
| 报错提示 99991672 或权限不足 | 检查应用身份权限中是否已开通并发布了 `im:message:readonly` 消息读取权限。 |
