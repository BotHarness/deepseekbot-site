Computer 的整套桌面环境——包括网站登录状态、书签、下载内容与工作文件——都保存在一个 Docker 具名卷上。通过**导出**功能可以将整个数据卷打包成单个归档文件，再通过**导入**功能在本机或另一台电脑上完整还原。

## 文件保存在哪里

- 所有持久化内容都存放在挂载于 `/config` 的 Docker 具名卷上（即容器内桌面用户的家目录）。即使删除容器，只要数据卷还在，你的 Computer 环境就完好无损。
- **工作区目录约定**：建议将你与 Bot 产出的文件放在 `~/workspace`（即 `/config/workspace`）。每次启动时如果该目录不存在会自动创建；它位于数据卷上，会随导出与导入一起迁移。浏览器的状态数据则单独存放在 `~/.config/chromium` 下。
- **导出目录**：宿主机（Host）上的保存路径，默认为 `~/Desktop/BotHarness Exports`（若没有 Desktop 目录则为 `~/BotHarness Exports`）。在支持目录选择器的环境中，你可以在 **Settings → BotHarness → Computer** 中修改路径。导出的归档文件会保存在该目录下，导入时也会从该目录中读取归档文件。

## 导出步骤

1. 打开 **Settings → BotHarness → Computer**。页面会直接显示当前的默认导出目录；如果当前环境支持目录选择器，也可以点击 **选择…** 更换保存位置。
2. 点击 **导出到…**（或 **导出**），选择目标目录并确认。Computer 会先安全关闭浏览器、停止容器并打包数据卷，若此前处于运行状态则会在打包完成后自动重启；界面会实时显示当前阶段与已用时间。
3. 导出完成后，界面会显示生成的带时间戳 `.tar` 归档文件路径。在固定导出目录的本地部署环境中，系统文件管理器还会自动打开该文件夹。

## 在另一台电脑上导入

1. 在目标电脑上安装容器运行时（Docker 或 Colima）以及安装了 BotHarness 的 DeepSeek Harness，先启动一次 Profile 让 Computer 插件完成初始化加载。
2. 将导出的 `.tar` 归档文件复制到目标电脑（可通过 U 盘、`scp` 或局域网共享传输）。
3. 打开目标电脑的 **Settings → BotHarness → Computer**，查看其导出目录路径，并将 `.tar` 归档文件放入该目录。
4. 点击 **导入…**，选中该归档文件并确认。Computer 会重建数据卷、解包归档并启动桌面——你的网站登录状态、书签和 `~/workspace` 中的文件都会完整恢复。

## 网页端下载与上传

在纯 Web 部署环境下（无法直接打开宿主机本地目录选择器），你可以通过浏览器直接下载和上传归档文件：

- **下载备份**：导出完成后点击 **下载**，即可通过浏览器的保存对话框下载归档文件。传输采用流式下载，约 1 GB 的大文件也不会占用过多内存。
- **上传并导入**：点击 **选择归档文件…** 挑选本地的 `.tar` 文件，再点击 **授权并导入** 即可流式上传并执行标准导入流程。上传完整完成后才会替换服务端同名的旧归档文件。

## 体积与耗时参考

- 导出的归档是数据卷内容的未压缩 `.tar` 文件。日常使用后，数据卷通常在 **1 GB 左右**（包含浏览器配置、缓存与工作区文件）；你可以直接查看生成的文件大小，或运行 `docker system df -v` 查看当前数据卷体积。
- 在常规电脑上，约 1 GB 的本地导出与导入通常各需**不到一分钟**（具体取决于磁盘读写速度；导入时还会确认所需的容器镜像是否就绪）。

## 妥善保管导出归档

归档文件中包含 Computer 内浏览器的 Cookie 和已保存的登录状态，敏感程度等同于完整的浏览器配置备份。请妥善保管和传输该文件。此外，Computer 归档属于整个 Profile 级别的导出，不会包含在单个 PersonaBot 的导出包中。

## 开发者诊断日志

如果遇到桌面画面连接异常，可以访问 `GET /api/computer/diagnostics` 查看按时间排列的生命周期、容器及画面查看器（Viewer）事件日志。Viewer 卡片会在日志中记录挂载、画面阶段切换、重连与重试详情，方便快速定位问题。
