你可以把任何一个 Bot 打包成一个 `.zip` 文件，直接发给朋友、同事，或者迁移到你的另一台电脑上。对方导入后，会得到一个拥有同样记忆与设定的新 Bot。与 [分享 Bot 到 Bot 市场](/zh/docs/share-bot) 不同，导出 zip 不需要 GitHub，也不会公开任何内容——文件只有在你主动发送给他人时才会离开你的电脑。

## zip 包含与不包含的内容

| 包含内容 | 不包含内容 |
| --- | --- |
| Bot 的 Memory 文件（包括尚未提交的修改） | 被 `.gitignore` 忽略的文件、符号链接 |
| `.botharness/bot.json`（名称、标签、简介）、头像图片和 `.botharness/banner.png` | 会话、聊天记录、Bot 收件箱 |
| 可选：Git 历史（所有分支、标签和提交记录） | IM 连接、工作区授权、模型设置、API 密钥与凭证 |
| | Git 远程地址、Git 配置和恢复检查点 |

## 导出 Bot

1. 打开要导出的 Bot 私聊，点击顶部的 Bot 名称打开资料页。
2. 点击资料页右上角的 **分享**（也可以在左侧消息列表中右键点击该 Bot，选择 **分享**）。

![Bot 资料页右上角的「分享」](/guides/bot-zip/02-export-section-zh.webp)

3. 在导出窗口中勾选要放入 zip 的文件。默认全部勾选；你可以点击文件夹前的箭头展开目录，取消勾选不想分享的文件或文件夹，也可以使用 **全选** 和 **全不选**。`.botharness/bot.json`、头像和横幅始终包含在内。
4. 如果想让对方看到这个 Bot 的记忆是如何一步步演化的，可以勾选 **包含 Git 历史**。
5. 点击 **导出**，浏览器会下载一个以 Bot 名称命名的 zip 文件。

![导出窗口：选择文件，并勾选「包含 Git 历史」](/guides/bot-zip/03-export-window-zh.webp)

### 分享前的隐私检查

Memory 文件中可能记录着你曾告诉过 Bot 的密码、API Key、个人信息或私人对话摘要。把 zip 发给别人之前，建议先在 **Bot 私聊 → Channel sidebar → [记忆文件](/zh/docs/channel-sidebar/memory-files)** 中浏览一遍，取消勾选不想分享的文件。

请注意，Git 历史记录中同样保存着过去删除或修改过的旧内容。因此，只有在**全选所有文件**时才能勾选 **包含 Git 历史**；一旦你取消勾选了任何文件，该选项就会自动禁用，以防对方从 Git 历史记录中翻出你排除的文件。如果不确定历史记录里是否有敏感信息，建议不要勾选包含 Git 历史。

## 导入 Bot

1. 点击左侧消息列表上方的 **＋（新建）→ 创建 Bot → 从 zip 导入**。

![「创建 Bot」的二级菜单：从零创建、从 GitHub 导入、从 zip 导入](/guides/bot-zip/01-create-menu-zh.webp)

2. 点击 **选择 zip 文件**，选中收到的 zip 包，然后点击 **导入**。

![从 zip 导入：选好文件后点「导入」](/guides/bot-zip/04-import-zh.webp)

导入成功后会创建一个全新的 Bot 并打开它的私聊：

- 名称、标签、简介、头像和横幅均读取自 zip 中的 `.botharness/bot.json`（旧版 zip 中的 `roles` 字段会自动作为标签导入；如果没有该文件，则默认使用 zip 文件名作为 Bot 名称）。
- 若 zip 不包含 Git 历史，新 Bot 的记忆库会生成一个干净的初始提交。
- 若 zip 包含 Git 历史，所有分支、标签和提交记录都会完整保留，并自动切换到导出时所在的分支；导出时尚未提交的修改在导入后仍保持未提交状态，可在 [记忆演化](/zh/docs/channel-sidebar/memory-evolution) 中查看。

![带历史导入后，「记忆演化」里能看到原来的分支和提交](/guides/bot-zip/05-imported-history-zh.webp)

导入后的新 Bot 与原 Bot 完全独立，双方后续的对话和记忆不会互相影响。你只需为新 Bot 按需配置模型、工作区授权和 IM 连接即可。

### 安全提示：只导入你信任的 zip

zip 中的文件会成为新 Bot 的常驻记忆，如果来源不明，可能包含诱导 Bot 执行不当操作的指令。请仅导入来自可信来源的 zip 文件，并在导入后先通过 **记忆文件** 检查内容。

如果 zip 文件不安全或已损坏，系统会直接拒绝导入并提示原因：

| 提示信息 | 原因与处理方式 |
| --- | --- |
| 这不是有效的 zip 文件，或文件已损坏。 | 下载不完整或文件已损坏。请重新下载，或请对方重新导出。 |
| zip 里有不安全的路径，已拒绝导入。 | 压缩包内包含试图写入目标目录之外的路径（如 `../`）或符号链接。请对方使用内置导出功能重新导出。 |
| zip 太大了 | 超过 100 MB 或 20,000 个文件。请对方在导出时取消勾选大文件，或取消包含 Git 历史。 |
| zip 里没有文件。 | 选错了文件，或者压缩包为空。 |

你用系统自带压缩工具将文件夹打包成的普通 zip 同样支持导入：如果所有文件都位于同一个顶层文件夹内，导入时会自动剥离顶层目录，并自动跳过 `__MACOSX` 和 `.DS_Store` 等系统生成的隐藏文件。
