我们收集匿名统计只有一个目的：**改善 Tobs，了解它被怎样使用、官网从哪里被访问**。使用统计不包含对话或 Memory 内容。可选账号、连接和通知所处理的信息在下文单独说明。做这件事的代码全部开源：[官网](https://github.com/BotHarness/deepseekbot-site)、[插件](https://github.com/BotHarness/BotHarness)，插件的设计记录在 [ADR-0132](https://github.com/BotHarness/BotHarness/blob/main/docs/adr/0132-anonymous-posthog-telemetry-and-campaign-short-links.md)。

统计数据存放在 [PostHog](https://posthog.com) 的美国区域，经由我们自己的域名 `t.botharness.ai` 转发。官网统计只用 IP 地址推断国家或地区，然后丢弃。插件和手机端事件禁用这类位置推断，不建立用户画像。

## 官网

第一次访问时右下角会询问你：

- **同意**：在本机保存一个随机的匿名 ID，这样你隔几天再来时，我们能知道你最初是从哪个帖子或视频来的。
- **拒绝**或不作选择：不在你的设备上保存任何标识（拒绝时只记住「已拒绝」这个选择），访问仍会以无 Cookie 的方式匿名计数（由服务器按天计算的不可逆哈希）。

我们记录的内容：访问了哪个页面、来源（`utm_*` 参数和 `?ref=`），以及少数核心按钮的点击，例如复制安装命令、点击 GitHub 或 Discord、播放宣传片、在 Bot 市场打开详情。站内搜索还会记录搜索词、结果数量和所选结果，用于改善指南。我们不录制会话，不使用广告追踪。

想改变选择，可以清除本站的 Cookie 和本地存储，下次访问会重新询问。

## 插件

插件的遥测默认开启，第一次启动时会提示一次。它只由插件的 Host 发送，只带一个首次启动时随机生成的安装 ID，不与官网访客关联。

会发送：插件和 DSH 版本、操作系统和架构；创建、归档、删除 Bot，从市场安装 Bot，启用连接器（只记类型，例如「飞书」），编辑头像这类事件；用到了哪些功能，例如搜索、活动中心、布局模式、模型方案、浏览器和电脑查看器、远程 Host 以及 Tob 委派，只记功能、固定选项（例如审批结果）和使用位置（桌面应用、浏览器、手机、CLI、Bot 工具或 IM）；每天的首次使用，用于统计活跃安装数；每天一次的汇总数量（Bot 数、会话数、消息数）；以及插件错误的类型和去掉了个人路径的堆栈。

每条事件都带有插件和 DSH 版本、操作系统和架构、Node.js 主版本、操作系统内核发行主版本、逻辑 CPU 数量区间（`1–2`、`3–4`、`5–8`、`9–16` 或 `17+`），以及总内存区间。内存区间依次以 4、8、16、32 GiB 为上限，超过 32 GiB 的设备统一归入 `64plus`。无法获取的信息记为 `unknown`。这些字段用于比较不同版本和设备类别；不会发送精确内存字节数、主机名、用户名或硬件序列号。

**不会写入事件数据**：Bot 名称、人格或 Memory 内容、对话文字、仓库地址、连接器凭据、文件路径、IP 地址。网络连接仍会向接收端基础设施暴露来源 IP；禁用位置推断并不代表网络传输不包含这项信息。

关闭方法，任选其一：

- 在 Tobs 设置中关闭使用统计
- 在插件配置里设置 `telemetry: false`
- 设置环境变量 `DO_NOT_TRACK=1`
- 设置环境变量 `BOTHARNESS_TELEMETRY=0`

## 手机应用

iPhone 和 Android 上的托布 Tobs 应用（原名 DeepSeekBot）是**你自己电脑**的遥控器。可用连接方式取决于手机应用和电脑端版本：局域网、[Tailscale](https://tailscale.com)，或可选的 Tobs Connect。Bot、Memory 和主要对话记录保存在你的电脑上；手机也会保存下述本地数据。

### 手机上的数据

- 配对凭证、设备密钥和已信任的电脑密钥保存在手机的系统安全存储中。iOS 上的配对凭证仅在手机解锁时可读，并绑定本机。可选账号会话也绑定本机，但重启后的首次解锁之后，应用即可读取该会话。
- 最近对话、未发送草稿，以及应用操作所需的文件，可能缓存在应用自己的存储中。

**取消配对**会移除这台手机保存的连接，并尝试在电脑上撤销其访问。如果未能完成撤销，请在电脑可连接时进入电脑的设备设置，选择**撤销**。这些操作不会删除电脑上的 Bot 或对话记录。

### 连接方式与可选 Tobs 账号

通过受支持的局域网或 Tailscale 方式配对，不需要 Tobs 账号。局域网连接使用加密的应用通道。Tailscale 连接使用你自己的 tailnet 和电脑的 HTTPS 地址；Tailscale 按其自身政策处理网络和账号信息。

当你选择把电脑关联到 Tobs 账号时，Tobs Connect 通过 [Cloudflare Tunnel](https://www.cloudflare.com/privacypolicy/) 提供连接路径。你通过 [WorkOS](https://workos.com/legal/privacy) 登录，可用方式包括 Apple、Google、邮箱验证码或邮箱与密码。

- WorkOS 处理账号邮箱、用户 ID 及提供的姓名，用于身份验证和账号管理。使用密码登录或注册时，应用通过 HTTPS 将邮箱和密码经 Connect 服务转交 WorkOS。应用和 Connect 服务不持久保存密码，也不将其写入应用日志或统计。WorkOS 负责密码验证、邮箱验证和密码重置。登录成功后，账号会话保存在手机的系统安全存储中。
- `connect.botharness.ai` 上的 Connect 服务保存用户 ID、关联电脑的标识和名称、关联时间及隧道配置。电脑地址使用 `<id>.botharness.dev` 等服务子域名；已有地址可能仍保留旧的 `deepseekbot.dev` 域名。请求配对时，手机名称和配对验证信息也会经过该服务。
- 手机和电脑使用同一 Tobs Connect 账号时，选择该电脑即可授权新手机，无需另行批准或手工核对指纹。此配对路径信任账号认证和 Connect 中继；任一方被攻破都可能导致未获本人同意的新设备授权，中继被攻破还可能在首次连接时替换电脑密钥。其他配对方式保留设备批准检查。Connect 应用数据按固定的电脑密钥在手机与电脑之间加密；已建立的连接遇到密钥或协议校验失败会拒绝连接，不会退回明文重试。你可以撤销已配对设备；若账号访问权被盗，还须保护账号，防止再次配对。
- 网络服务商仍会处理 IP 地址、目标地址、连接时间和流量大小等元数据。这项通道保护不涵盖下文单独说明的语音和通知服务。

### 删除账号

**不安装 App 也能申请删除**：请使用 Tobs 账号的注册邮箱，向 [yang@deepseekbot.app](mailto:yang@deepseekbot.app?subject=Tobs%20account%20deletion) 发送邮件，主题为 **Tobs account deletion**，说明希望删除 Tobs 账号及其关联账号数据。无需安装或登录 App。我们会先核验账号归属，再处理请求；请勿发送密码或验证码。核验后的邮件请求会删除下文所述的账号和 Connect 关联记录，保留范围及安全记录与下文相同。

在手机上打开配对页面，选择 Tobs 账号入口，按需登录，再选择**删除账号**并确认。请求会删除 WorkOS 账号，移除该账号关联的电脑记录、隧道和地址，并清理这台手机上的账号会话及其关联连接。如果服务请求或本地清理失败，应用会显示失败或待清理状态，供你重试，不会把尚未完成的删除显示为成功。

Connect 服务会保留包含用户 ID 和删除时间的最小删除记录，用于拒绝旧账号凭据；该记录目前不会自动过期。删除账号不会清除你电脑上的 Bot、对话或文件，也不会撤销通过局域网或 Tailscale 独立配对的设备；如需移除这些设备，请在电脑的设备设置中操作。在某台电脑上退出登录只会解除这台电脑的关联，与删除整个账号不同。

### 消息、文件与模型服务

消息、附件和编辑后的听写文字会发送给已配对电脑。电脑可能再把内容交给你在那里配置的模型服务商、工具和消息平台处理。这与使用统计及可选账号服务相互独立。发送敏感内容前，请检查你选择的服务及其隐私政策。

### Bot 通话与共享画面

在受支持的应用和电脑版本中，开始 Bot 通话会将麦克风媒体发送到已配对电脑。这与键盘听写不同。电脑可将语音发送给配置的语音识别服务商，将识别后的对话发送给模型服务商，并将回复文字发送给语音合成服务商。服务商的处理及保留方式取决于该电脑上的配置。结束通话会停止后续通话采集，不会删除已经保存的对话消息。

在受支持的通话中开启相机共享后，选取的相机帧会发送到已配对电脑。开启画面保存可将这些图片加入对话；关闭后不会生成这些对话附件，但模型使用的图片仍可能保留在其会话工具结果中。因此，该开关不代表完全不存储。桌面屏幕共享是另一项电脑端功能，需要相应的用户授权。

### 商店审核演示电脑

商店审核员使用我们提供的账号和演示电脑时，该电脑由我们运营。因此，审核消息、附件、Bot 记忆和执行记录可能由维护人员及配置的模型服务处理。演示环境与个人电脑隔离，只供测试内容使用。删除账号或取消配对不会清除演示电脑上的对话记录；如需删除，请通过下方联系方式提出。

### 权限与通知

- **相机**：扫描配对码、拍摄你要发送的照片，或在受支持的 Bot 通话中共享相机帧。
- **照片**：选择你要发送的照片。
- **麦克风和语音识别**：用于听写及受支持的 Bot 通话。听写时，应用接收识别文字供你检查和修改。识别由设备的语音服务处理；根据平台、语言和服务可用情况，音频可能由 Apple 或 Android 上的识别服务商处理。应用不强制离线识别，不保存听写音频文件，也不会把该音频上传给你的电脑或 Tobs 账号服务。
- **通知**：可选。手机获取 Expo 推送令牌，并将它登记到你的电脑。电脑经由 [Expo 推送服务](https://docs.expo.dev/push-notifications/faq/) 及 Apple（APNs）或 Google（FCM）发送通知。载荷可能包含电脑、设备、Bot 或频道的标识和名称、通知类型、角标数量，以及一小段消息或工具请求预览。工具预览可能包含命令、网址、路径或其他参数摘要；私密输入的值不会加入这些预览。通知服务商对这些载荷的处理独立于加密的 Connect 通道。不希望继续收到通知时，可以在应用或系统设置中关闭。

### 统计

在启用了统计功能的构建中，手机应用会记录打开应用、配对尝试及结果、连接结果与粗粒度耗时区间，首次消息被接受等启用进度，创建和导入 Bot 的尝试及结果，以及功能使用：回答审批和提问、授权文件夹、修改模型方案、打开通知、搜索结果、Tob、浏览器和电脑查看器，以及分享给 Bot。功能事件只记功能和固定选项，例如审批结果或分享里是否有文字或文件，不记内容。此类构建默认开启统计，并提供提示和设置开关；统计不会等你关闭提示才开始。在手机应用设置中关闭「使用统计」，即可停止收集并删除待发送事件和随机安装 ID。手机端设置与 Host 设置相互独立，标识也不与官网访问或 Host 身份关联。

每条事件带有随机安装 ID、前台会话 UUID、应用版本和构建号、iOS 或 Android 平台、应用语言和构建环境、系统主次版本、手机或平板类别、总内存区间（与插件相同），以及用于估计硬件能力的设备年份等级。iOS 能获取时，还会包含 `iPhone11,6` 这样的公开机型标识，同一机型共用该标识；Android 的此字段记为 `unknown`。无法获取的设备信息也记为 `unknown`。

这些统计只发送白名单明确允许的字段；这里的排除项不代表前述账号和通知服务处理的数据范围。不会发送设备名称、广告 ID、Android ID、序列号、精确内存字节数、配对链接、凭据、推送令牌、Host 地址、对话文字或 Memory。应用不录制会话，不自动采集崩溃。此次统计不包含定期 CPU 或内存占用采样、帧率测量或启动耗时。

再次开启统计会生成新的随机 ID。详见[手机统计说明](https://github.com/BotHarness/DeepSeekBot/blob/main/docs/mobile-statistics.md)。

我们不出售数据，不使用广告标识，也不跨应用或网站追踪你。
