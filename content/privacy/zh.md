我们收集匿名统计只有一个目的：**改善 Tobs，了解它被怎样使用、官网从哪里被访问**。我们不收集能识别你本人的信息，也不收集你的对话或 Memory 内容。做这件事的代码全部开源：[官网](https://github.com/BotHarness/deepseekbot-site)、[插件](https://github.com/BotHarness/BotHarness)，插件的设计记录在 [ADR-0132](https://github.com/BotHarness/BotHarness/blob/main/docs/adr/0132-anonymous-posthog-telemetry-and-campaign-short-links.md)。

统计数据存放在 [PostHog](https://posthog.com) 的美国区域，经由我们自己的域名 `t.botharness.ai` 转发。官网统计只用 IP 地址推断国家或地区，然后丢弃。插件和手机端事件禁用这类位置推断，不建立用户画像。

## 官网

第一次访问时右下角会询问你：

- **同意**：在本机保存一个随机的匿名 ID，这样你隔几天再来时，我们能知道你最初是从哪个帖子或视频来的。
- **拒绝**或不作选择：不在你的设备上保存任何标识（拒绝时只记住「已拒绝」这个选择），访问仍会以无 Cookie 的方式匿名计数（由服务器按天计算的不可逆哈希）。

我们记录的内容：访问了哪个页面、来源（`utm_*` 参数和 `?ref=`），以及少数核心按钮的点击，例如复制安装命令、点击 GitHub 或 Discord、播放宣传片、在 Bot 市场打开详情。我们不记录你输入的文字，不录制会话，不使用广告追踪。

想改变选择，可以清除本站的 Cookie 和本地存储，下次访问会重新询问。

## 插件

插件的遥测默认开启，第一次启动时会提示一次。它只由插件的 Host 发送，只带一个首次启动时随机生成的安装 ID，不与官网访客关联。

会发送：插件和 DSH 版本、操作系统和架构；创建、归档、删除 Bot，从市场安装 Bot，启用连接器（只记类型，例如「飞书」），编辑头像这类事件；每天一次的汇总数量（Bot 数、会话数、消息数）；以及插件错误的类型和去掉了个人路径的堆栈。

每条事件都带有插件和 DSH 版本、操作系统和架构、Node.js 主版本、操作系统内核发行主版本、逻辑 CPU 数量区间（`1–2`、`3–4`、`5–8`、`9–16` 或 `17+`），以及总内存区间。内存区间依次以 4、8、16、32 GiB 为上限，超过 32 GiB 的设备统一归入 `64plus`。无法获取的信息记为 `unknown`。这些字段用于比较不同版本和设备类别；不会发送精确内存字节数、主机名、用户名或硬件序列号。

**不会写入事件数据**：Bot 名称、人格或 Memory 内容、对话文字、仓库地址、连接器凭据、文件路径、IP 地址。网络连接仍会向接收端基础设施暴露来源 IP；禁用位置推断并不代表网络传输不包含这项信息。

关闭方法，任选其一：

- 在 Tobs 设置中关闭使用统计
- 在插件配置里设置 `telemetry: false`
- 设置环境变量 `DO_NOT_TRACK=1`
- 设置环境变量 `BOTHARNESS_TELEMETRY=0`

## 手机应用

iPhone 和 Android 上的 DeepSeekBot 应用是**你自己电脑**的遥控器。它没有 Tobs 账号，中间也没有 Tobs 服务器：它只通过你的 [Tailscale](https://tailscale.com) 网络（`*.ts.net` 或 `100.x` 地址，始终 HTTPS）连接你配对的那台电脑。你的 Bot、Memory 和对话都留在那台电脑上。

**保存在手机上的**

- 每台已配对电脑的配对凭证，只保存在 iOS 钥匙串或 Android Keystore 加密的安全存储里，只在手机解锁时可读，也无法恢复到其他设备上。
- 最近对话和未发送草稿的缓存，用来让应用打开更快，保存在应用自己的存储里。

要移除一台电脑和它的凭证，在应用里打开这台电脑，选择**取消配对**。也可以在电脑的设置里撤销这台手机。

**只发给你的电脑的**

你输入的消息、附带的照片和文件、语音听写得到的文字，只发送到已配对的电脑，我们收不到。

**权限，只在你操作时使用**

- **相机**：扫描电脑上的配对码，或拍一张你要发送的照片。
- **照片**：选择你要发送的照片。
- **麦克风和语音识别**：只在你点按听写按钮后、停止之前使用。由手机系统自带的语音服务（Apple 或 Google）把语音转成文字，适用该服务商自己的隐私政策；文字发送前你可以看到并修改。不录音，也不会把音频发给你的电脑或我们。
- **通知**：可选。允许后，手机只把推送令牌交给已配对的电脑。Bot 需要你时，电脑经由 [Expo 推送服务](https://docs.expo.dev/push-notifications/faq/) 把一条简短通知（Bot 或频道名称和一小段预览）交给 Apple（APNs）或 Google（FCM），再送达你的手机。Expo 会保留推送令牌以便之后送达通知，但不会在送达所需之外保留通知内容。随时可以在应用或系统设置里关闭通知。

**统计**

在启用了统计功能的构建中，手机应用会记录打开应用、配对尝试及结果、连接结果与粗粒度耗时区间，以及首次消息被接受等启用进度。此类构建默认开启统计，并提供提示和设置开关；统计不会等你关闭提示才开始。在手机应用设置中关闭「使用统计」，即可停止收集并删除待发送事件和随机安装 ID。手机端设置与 Host 设置相互独立，标识也不与官网访问或 Host 身份关联。

每条事件带有随机安装 ID、前台会话 UUID、应用版本和构建号、iOS 或 Android 平台、应用语言和构建环境、系统主次版本、手机或平板类别、总内存区间（与插件相同），以及用于估计硬件能力的设备年份等级。iOS 能获取时，还会包含 `iPhone11,6` 这样的公开机型标识，同一机型共用该标识；Android 的此字段记为 `unknown`。无法获取的设备信息也记为 `unknown`。

只发送白名单明确允许的字段。不会发送设备名称、广告 ID、Android ID、序列号、精确内存字节数、配对链接、凭据、推送令牌、Host 地址、对话文字或 Memory。应用不录制会话，不自动采集崩溃。此次统计不包含定期 CPU 或内存占用采样、帧率测量或启动耗时。

再次开启统计会生成新的随机 ID。详见[手机统计说明](https://github.com/BotHarness/DeepSeekBot/blob/main/docs/mobile-statistics.md)。

我们不出售数据，不使用广告标识，也不跨应用或网站追踪你。
