**DeepSeekBot 1.4.0 已正式发布到 npm。** 本文介绍从 1.3.1 到 1.4.0 的核心变化，完整条目见[更新日志](/changelog/#v1.4.0)。[安装指南](/docs/installation/)已同步精确版本 `deepseekbot@1.4.0`。

这次更新的重点，是让一组有身份、有记忆的 Bot 更容易管理，也让你更方便地查看进展、处理决定和安排工作。

## 托布与 Home：从一句话开始管理

新增本地总管**托布（Tob）**。你可以在 Home 发起对话，让它创建带人格和初始记忆的 Bot、建群、邀请成员，或调整模型与部分运行设置。管理操作沿用原有审批和权限检查。

Home 保留输入框和可编辑的欢迎称呼，下方只放 **Token 历史图表**与 **Bot 活跃情况**。宽面板两列，窄面板上下排列；点 Bot 就回到原来的私聊。快捷提问先填入草稿，由你决定何时发送。

### 新手引导：从配置模型走到真实对话

Desktop 新引导带你配置模型、和托布创建 Bot、创建群聊，再学习面板布局。最后实际点击 Home 标题关闭它，进入原来的托布私聊。新建 Bot 不再自动插入默认欢迎消息；旧用户已完成或跳过的状态也会保留。

## 工作区：按自己的方式摆放面板

消息、会话、记忆、定时任务、浏览器和电脑控制，可以在适用的桌面宽屏布局里按需展开、拖拽分割和调整大小。消息内的子面板也能组成嵌套行列，按频道记住布局。

这一轮还修复了面板开关的圆角边框裁切、拖动分割线时的尺寸回跳，以及关闭重开后的比例恢复。Home 开关保留周围布局，减少反复调整。在 macOS Desktop 中，图标加标题是面板的开关与拖拽区域；标题栏和控制列的空白用于移动窗口，减少误拖整个面板。

## 自动审批：把规则写清楚

为 Bot 选择内置审批模板，或用 Markdown 编写自己的规则，并可单独指定审批员模型。审批结果会留下可查看的记录；拿不准或发生错误时，仍交给你处理。

自动审批拒绝的操作会进入待办，你可以对同一次调用选择「仍然允许这一次」。连续拒绝达到阈值时，当前会话会暂停自动审批。适用的密钥工具复核只读取脱敏参数，不读取密钥值。

## 聊天与 IM：更容易找到、接住和继续

- **更顺手的聊天：**拖入附件、会话内搜索、表情回应、未读定位、免打扰，以及快速切换与可自定义快捷键；聊天中也能让 Bot 创建新 Bot。
- **更直接的模型切换：**Bot 右键菜单与私聊里的 `/model`、`/effort`，用于选择模型和推理强度。
- **IM 快捷命令：**在已授权的私聊中用 `/help`、`/status`、`/model`、`/stop`、`/new` 等命令直接操作，不必先启动一次模型回复；修改类命令仍检查权限。
- **微信私聊衔接：**可选择把扫码绑定者的微信私聊镜像到本地，或把本地私聊转发回同一账户；两个开关默认关闭，本地审批和私密输入卡片不会外发。
- **群聊可靠性：**修复 Bot 的文字 @ 提及与唤醒，并可按群启用回复复核，让 Bot 在新消息到达后检查旧草稿、放弃重复答复，或在中断后显式恢复。

## CLI 与记忆：更多操作可以直接完成

命令行扩展了在线 Host 的 Memory、定时任务、群组、Inbox、模型、用量、IM、Bot 市场与更新管理。浏览器、电脑及适用的 Bot 工具可以绕过模型直接调用，配合 `bot-trace` 定位问题。

创建 Bot 时可以指定记忆目录，已有 Bot 的 Memory 也可以迁移到其他文件夹，保留聊天和记忆历史。模型、工作区、Token 和生成速度等输入框底栏项目可以按自己的习惯显隐、排序。

## 手机开发版：继续跟进电脑上的工作

手机开发版新增或增强了扫码配对、多电脑切换、原生群聊、附件、语音转文字、审批与提问卡片、通知、定时任务和用量查看。浏览器与本机电脑可在获得权限后观看和接管；长回复渲染、键盘遮挡、返回导航与系统字号适配也有一轮改进。

这些是**手机开发版的进展**，不代表本次 npm 更新会自动安装手机 App，也不代表已经在 App Store 或 Google Play 正式上架。通知与设备能力取决于具体构建和配置。

另外，开发／UAT 云协作已加入工作区、频道、邀请与访客、频道 Agent 及健康检查入口；它仍是单独的试用范围，不作为本次公开云服务承诺。

## 兼容性与发布安排

1.4.0 声明的 DSH 安装范围是 `>=0.2.0-rc.2 <0.3.0-0`。正式发布的同一组包已在 **DSH 0.2.0-rc.2 与 0.2.1-rc.2** 完成全新安装、Host 启动、Bot／DM 创建及重启持久化验证。推荐使用 0.2.1-rc.2；允许其他 0.2.x 安装，不代表每个版本都已完成运行验收。

升级前请备份 Profile。1.4.0 包含数据结构升级，回退到旧二进制可能需要恢复升级前的备份。开始使用请看[安装指南](/docs/installation/)，或查看 [GitHub Release](https://github.com/BotHarness/DeepSeekBot/releases/tag/v1.4.0)。
