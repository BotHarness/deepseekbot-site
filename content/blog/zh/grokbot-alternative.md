搜 "grokbot alternative" 的人通常已经用过 Grok Bot：一群常驻的 AI 同事，各有名字和分工，跑在服务方的云端电脑上，随时在线。它确实省心，但有个前提——那不是你的机器，也不是你能审计的代码。这篇文章只回答一个问题：如果你想找一个开源、自托管的平替，该按什么标准挑；DeepSeekBot 哪几条对得上，哪条对不上。

## 先说结论

- Grok Bot 是云端托管服务；DeepSeekBot 是装在自己机器上的开源软件（MIT 许可）。
- 四条硬指标里最容易被忽略的是**记忆归谁**：DeepSeekBot 的记忆就是一个普通的 Git 工作树，随时能看 diff、切分支、推到远端。
- 迁移只需四步，不用重写现有工作流；但如果你想要的是“今天就把 Bot 搬到 Telegram”，DeepSeekBot 目前还没内置 Telegram 接入，可以先观望。

## 为什么会找 GrokBot 平替

- **数据位置**：Bot 的文件、对话历史与累积的上下文都留在服务方云端。
- **黑盒与迁移限制**：看不到源码，也没法把整套环境搬到自己的服务器上。
- **模型绑定**：底层用哪家的模型由服务方决定，没法按需切换。
- **计费与套餐边界**：团队与企业级能力按套餐等级解锁，使用边界由平台划定。

（Grok Bot 的具体能力与价格以 x.ai 官方页面为准，这里仅做架构层面的结构性对比。）

## 挑平替的四条硬指标

1. **身份与人格**：Bot 是不是长期存在的“同事”——有自己的名字、性格和判断方式？
2. **记忆的形态**：记忆存在哪、由谁保管、你能不能自己直接打开看和改？
3. **多人协作**：多个 Bot 能不能保留各自身份一起干活，能不能只叫醒该醒的那一个？
4. **自托管与模型自由**：能不能跑在自己的机器上，自由接入自己想用的模型？

## DeepSeekBot 逐条对照

- **身份**：每个 PersonaBot 都有自己的名字和头像。在 [SOUL.md 与核心记忆](/docs/soul-and-core-memory/)机制下，`SOUL.md` 保存人格、表达方式与工作原则，`MEMORY.md` 保存核心记忆，跨对话和跨文件夹持续生效。
- **记忆**：记忆本身就是一个普通 Git 工作树。你可以在侧栏直接浏览[记忆文件](/docs/channel-sidebar/memory-files/)、分支、commit 与 diff，也能推送到自己的 GitHub 仓库，在多台机器之间同步同一份记忆。
- **协作**：把不同的 Bot 拉进同一个 [Group](/docs/channel-sidebar/groups/)，每条消息都保留各自身份，@ 谁就唤醒谁；每个成员可以单独设置消息提醒级别（每条提醒、摘要、仅提及或静默）。
- **自托管与模型自由**：DeepSeekBot 是一个安装在 DeepSeek Harness（DSH）桌面端里的 npm 插件；你在 DSH 里接入的任何模型 provider，Bot 都能直接调用。项目采用 MIT 许可，源码在 GitHub 完全公开。
- **另外两项实用能力**：跨文件夹工作（授权文件夹后，同一个 Bot 在不同项目目录里各有独立会话和进展）；定时任务（按计划在应用运行时自动执行，可随时暂停，也能锁定任务防止被 Bot 自行修改）。

## 一张对比表

| | Grok Bot | DeepSeekBot |
| --- | --- | --- |
| 运行位置 | 服务方的云端电脑（托管） | 你自己的机器（自托管） |
| 源码 | 闭源 | MIT 开源，GitHub 可查 |
| 记忆 | 由服务方管理，上下文持续累积 | 普通 Git 工作树，可读、可分支、可推送 |
| 模型 | 服务方提供 | DSH 里接入的任何 provider |
| 协作 | 团队 Bot、在 X 上 @bot | Group 内多 Bot，各自身份与提醒级别 |
| 接入面 | X、官方桌面与移动客户端、Google Workspace 集成 | 微信 / QQ / Lark / Slack / Discord |
| 计费 | 套餐制（含团队与企业） | 软件开源免费，模型与机器成本自付 |

## 四步迁移路径

1. 还没装 DeepSeek Harness？先下载并安装 DSH 桌面端。
2. 打开 DSH，点击左侧「插件」→「添加插件」，输入 `deepseekbot`，安装后点击「立即启用」。
3. 侧栏出现「Bot 模式」后，创建你的第一个 PersonaBot，写好它的 `SOUL.md` 和 `MEMORY.md`。
4. 接入常用 IM：支持飞书 / Lark、Slack、Discord 或个人微信（个人微信仅接收扫码者本人的私聊）。只需在设置中连接应用，再从私聊侧栏的「外部身份」完成绑定，发条消息就能开始测试。

更多配置细节见[文档总览](/docs/overview/)与[安装指南](/docs/installation/)。

## 什么时候别换

- 你的工作流高度依赖在 X 上直接 `@bot`，或者重度使用 Grok 官方移动端与 Google Workspace 原生集成——这些是 Grok Bot 的主场能力，DeepSeekBot 没有直接对应物。
- 你的核心入口是 Telegram——DeepSeekBot 目前尚未原生接入。
- 你不想自己维护一台常开的机器：自托管意味着宿主机在线状态、版本更新和模型 API 账单都需要自己打理。

## 常见问题

**DeepSeekBot 免费吗？** 软件本身基于 MIT 许可开源免费；模型 API 调用与运行机器的成本由你自己承担。

**能接自己的模型吗？** 能。只要在 DSH 里配置好的模型 provider，Bot 都能直接选用。

**记忆存在哪？** 存在你自己的机器上，本质上就是一个本地 Git 仓库，随时可以查看 diff 和回滚。

**多人一起用行吗？** 行。Group 里每个 Bot 保留独立身份，成员也能各自设置提醒级别。

想试试的话，直接打开 DSH 的「插件 → 添加插件」，输入 `deepseekbot`，装好后顺着[文档总览](/docs/overview/)一步步配起来即可。
