**托布 Tobs 1.6.0 已正式发布到 npm。**

从 1.5 探索跨设备移动端协作以来，我们收到了大量来自日常工作流的宝贵反馈。如何让一个由多个专属 AI Bot 组成的团队更自然地融入桌面工作，如何让调试出心仪 Bot 的开发者放心地将创意分享给社区，以及如何让复杂的后台长任务变得清晰可控，构成了本次 1.6.0 更新的核心主线。

本次正式发布的桌面安装包为 `@botharness/tobs@1.6.0`。你可以参考[安装指南](/docs/installation/)进行更新，完整细节请参阅[更新日志](/changelog/#v1.6.0)。

下面我们来看看 1.6.0 带来的重点改变。

## 简洁布局模式：更专注的对话与收放自如的工具箱

Tobs 此前的多列并排工作区深受高阶用户喜爱——你可以把消息、记忆、会话、定时任务、内置浏览器和电脑控制面板同时平铺在屏幕上。但在笔记本屏幕或只需专注与某个 Bot 交流的日常场景中，多列并排往往显得信息过载。

1.6.0 为此带来了**简洁布局模式（Simple Layout Mode）**，并将其作为新用户的默认视图：

- **Control Rail 侧边导航**：左侧细栏提供全局切换能力，点击即可在首页（Home）、活动中心（Activity）、消息对话（Messages）与插件面板之间快速跳转，再次点击当前按钮即可收起侧栏，整体操作类似于现代化编辑器的活动栏。
- **开阔清爽的对话视窗**：在消息视图中，左侧是频道列表，右侧始终保留开阔的对话区域，不再被其他面板切碎。
- **抽屉式子面板栏（Subpanel Drawer）**：点击消息标题栏右侧的面板按钮，即可在对话右侧呼出该频道的子面板抽屉。会话管理、记忆文件（`SOUL.md` 和 `MEMORY.md`）、记忆演化、定时任务、浏览器和电脑操作全部按固定顺序整齐排列。每个子面板都可以独立折叠展开，支持拖拽调整宽度和高度。更重要的是，当你折叠浏览器或电脑视窗时，界面虽然隐藏，但 Bot 在后台的操作依然在正常进行，绝不中断。

老用户已配置的多列高级布局（Advanced Layout Mode）将完整保留，绝不强行重置。你可以在 **Bot 设置 → 界面设置**（或外观设置）中自由切换这两种模式，它们会各自独立记忆你所调整的窗口位置与尺寸。

## Bot 市场直接分享：零门槛发布，但隐私与安全绝不妥协

随着越来越多用户打造出富有特色的人格 Bot，社区对分享与交流的需求日益增长。此前分享 Bot 通常需要建立专门的 GitHub 仓库并配置复杂的元数据，阻碍了许多优质创意的流通。

1.6.0 全面开放了 **Bot 市场直接上传与安全审查体系**：

### 1. 登录即可直接上传
只要使用 Tobs Connect 账号登录，并设置一次作者名称，你就可以直接在应用内将本地调试好的 Bot 打包上传到市场。任何社区用户都可以将其一键安装为全新的独立 Bot，仅携带初始提交历史，不影响你的原始环境。

### 2. 托布担任隐私审查助理（Sharing Drafts）
我们深知，长期相处的 Bot 其记忆文件中难免沉淀了个人的私密工作细节或生活偏好。为了防止无意中泄漏敏感数据，当你在 Bot 资料页点击**“分享到市场”**时，托布（Tob）会介入协助：
- 它会将 Bot 的文件复制为一份独立的分享草稿；
- 陪你逐个文件过目，一旦发现可能涉及个人隐私、内部凭据或私密记录的内容，会主动询问你是**保留、改写还是剔除**；
- 最终上传到市场或推送到公开仓库的，仅是经过审查确认的干净草稿，不会改动你本地真实的记忆库，也不会带上本地私密的 Git 提交历史。

### 3. 安装前安全与注入审查（Pre-install Review）
从社区或外部链接引入一个全新的 AI 智能体时，安全防范同样不可忽视。在 Tobs 1.6.0 中，无论是官方市场条目还是通过 Git 链接导入的 Bot，托布在安装前都会对其 Prompt 规则和内嵌脚本进行自动化安全扫描：
- 识别潜在的 Prompt Injection（指令注入）隐患；
- 检查是否存在试图将本地上下文或隐私数据发送到外部未知域名的指令；
- 在用户确认安装前列出完整的安全审查清单，确保每一次引入都透明、安心。

此外，Bot 市场面板本身也迎来了全新改版，推出了包含每日精选、竖版海报热榜与新上架紧凑卡片的发现首页，查看 Markdown 说明与文件分布更加直观。

## Assignment 执行时间线：复杂的长任务，现在清晰透明

在多智能体协同场景中，主协调器（Orchestrator）通常会将耗时较长的复合任务包装为委托任务（Assignment），并分派给多个具有特定专长的子智能体（Subagent）。此前这类长任务往往像一个黑盒，用户只能等待最终结果。

1.6.0 推出了全新的 **Assignment 执行时间线（Assignment Timeline）**：

- **按轮次拆解**：时间线以清晰的轮次（Turn）为维度，忠实还原 Orchestrator 提出任务时的初始要求，以及后续每一轮追加的指令摘要。
- **主步骤与 Subagent 全景可视**：在每个轮次内部，主执行步骤（MAIN）与派发出的 Subagent 清晰分层呈现。你可以随时展开查看每个 Subagent 的执行状态、实际调用的模型名称、推理强度以及工具调用详情。
- **统一准入与健壮权限校验**：无论是 Host 宿主重启、网络重连，还是通过移动端接管会话，系统在每一步开始前都会自动将环境权限对齐到任务创建时的快照，彻底消除了过往因权限模式不一致导致的偶发性中断。
- **思考状态与可控中断**：针对耗时较长的长任务，Bot 在准备阶段会明确展示“思考中”状态。如果模型响应异常或需要人工干预，随时可以点击停止，优雅结束当前轮次，而不会造成会话阻塞。

## IM 互联与跨设备体验全面进化

除了桌面工作区本身的进化，1.6.0 还将多端互通的质感提升到了新的水准：

- **Bot 间相互 @ 与循环协作**：在飞书和 Discord 群聊中，其他 Bot 明确 @ 你的 Bot 时可以被正常唤醒并基于上下文回复，多轮任务交接不再卡壳；同时系统内置了 32 跳的协作上限机制，有效拦截失控死循环。
- **QQ 与飞书富文本升级**：内置 IM 引擎升级至最新稳定版，QQ 支持私聊接入、图片/图文混排与并发 429 自动重试；飞书 Bot 回复全面改用原生 Markdown 卡片，加粗、列表、表格和代码块均可精美呈现。
- **Android Material 3 Expressive**：移动端 Android 全面适配最新的 Material 3 规范。支持随手势滑动的全局工作区抽屉、可展开的 FAB 操作胶囊、浮动标签输入框，以及更加细腻的系统级预测性返回手势。
- **iOS 原生质感与 Sheet 体系**：iOS 端统一采用系统原生 Sheet 与 Form 规范，适配 SwiftUI 弹簧阻尼手感与 Liquid Glass 视觉效果。Bot 资料页采用大图 Header 与分段控制器，记忆变更提供代码评审级别的逐行 Git Diff 视图。
- **全电脑环境无缝汇聚**：在移动端“全部环境”中，分散在不同物理电脑上的 Bot 会话与动态被智能聚合。你可以随时从一部手机查看远端电脑的工作进展，审批敏感工具调用。

## 升级与开始使用

Tobs 1.6.0 现已就绪。你可以通过以下方式快速升级：

```bash
# 全局更新 Tobs 命令行与桌面端
pnpm add -g @botharness/tobs@1.6.0
# 或使用 npm
npm install -g @botharness/tobs@1.6.0
```

推荐配合使用 **DeepSeek Harness 0.2.1**。在进行大版本升级前，建议在应用的 **设置 → 环境备份** 中导出一份配置备份。

如果需要了解更多细节，欢迎查阅[更新日志](/changelog/#v1.6.0)与[官方文档](/docs/)。如果你对新功能有任何想法或建议，随时欢迎加入我们的社区交流群与开发者团队沟通！
