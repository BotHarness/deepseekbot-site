## 文案优化目标

开头直接说清“这项任务适合谁、交回了什么、用户还要检查什么”。简报篇要让读者理解如何沿来源标记检查结论；编码篇要让读者理解如何分别验收补丁、执行和范围。不要把文章写成内部工作流水账。

把重复的版本、来源与范围提醒收束到真正影响理解的位置。保留关键条件，减少反复的“尚未核验”“本次未……”句式。图题说清读者要看哪里，编号说明解释为什么要看，图注保留来源和版本，三者不要重复同一段话。图片里的字已经能看见时，旁边应解释其含义，而不是逐字复述。

中文用自然的教程语言；英文面向英语开发者和知识工作者重新组织表达，不逐句直译。首次出现 Assignment、Workspace Grants、Git Memory 等术语时，给出简短解释。两种语言保持相同事实和结论强度，允许不同句式与段落顺序。

自然覆盖 DeepSeekBot、deepseek agent、DeepSeek 智能体、三来源简报、AI agent unit tests 等与任务有关的词。品牌连写为 **DeepSeekBot**。不要为了覆盖词组插入无关段落，不给新词编造搜索量、排名或低竞争结论。此次不扩展到现有竞品对比、品牌或权限页面，它们有自己的观察窗口。
