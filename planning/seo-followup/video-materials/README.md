## 素材交接与锁稿

1. 从任务所有者取得已经脱敏且允许公开的输入／输出／日志／画面及来源指针；不要复制私有 Profile、密钥或聊天数据库。
2. 在实拍清单对应的镜头旁记录具体文件、版本、任务证据位置和人工审核结论。即使运行不成功，也保留真实失败路径；不要为了匹配脚本改写输出。
3. 先锁事实，再决定中文与英文的自然措辞、剪辑长度、配音和画面。来自同一录屏的英文字幕版可以复用证据，但不得说“这是第二次英文运行”。
4. 真人选定并改写结果分支，填齐发布栏位；按最终画面产生字幕时间轴与章节。任何结果变化要重新审核两种语言。
5. 依据平台表单决定适用声明。只有审阅通过的最终版本才能进入发布审批；本 PR 不上传、投递、合并或部署。

国家／语言／设备沿用对应母任务最后确认的切片，并记录所用来源；没有新设 tracker、付费查询或通用默认市场。视频播放、点击、安装意向与有效试用分开交给 #79 的报告口径，未取得指标仍为 `unknown`。
